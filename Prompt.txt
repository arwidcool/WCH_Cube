The agent launcher prompt has moved.

    agents/PROMPT.txt      the prompt template. Only the agent number changes.
    agents/run_agents.ps1  starts one Claude Code session per agent from it.

This file used to hold the whole prompt and point at "Agents Rounds 3/", a folder that no
longer exists. To start the agents:

    powershell -File agents\run_agents.ps1            # all three
    powershell -File agents\run_agents.ps1 -DryRun    # print what it would do

run_agents.ps1 substitutes AGENT-N in PROMPT.txt with the agent's number, appends that
agent's own agents/AGENT_n_*.md, and launches the session.
